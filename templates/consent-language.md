# Consent language samples

## Web / app checkbox (recommended)

```
☐ I agree to receive SMS from [Brand] at the number I provide about [coaching / notifications].
  Message frequency varies. Msg & data rates may apply. Reply STOP to cancel, HELP for help.
  Consent is not a condition of purchase. See Privacy Policy: [URL]
```

## Keyword opt-in (if used)

User texts `JOIN` or `YES` to your long code after seeing the same disclosure on a landing page.

Auto-reply:

```
[Brand]: You’re subscribed to SMS [coaching/alerts]. Msg frequency varies. Msg & data rates may apply.
Reply HELP for help, STOP to cancel. Privacy: [URL]
```

## Age gate (dating / social)

```
You must be 18+ to opt in to SMS from [Brand]. By checking this box you confirm you are 18 or older
and consent to SMS as described above.
```

## Recordkeeping minimum

Store: phone E.164, timestamp (UTC), IP or device id if available, disclosure version id, source surface, user account id.
